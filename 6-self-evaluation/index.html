Self-Assessment

During my internship at Amazon Web Services Vietnam Company Limited from April 17, 2026 to July 30, 2026, I had the opportunity to work in a professional environment, gain practical experience in the software development process, and apply the knowledge acquired at university to a real-world project.

During the internship, I participated in the research and development of the Serverless Video-on-Demand Platform on AWS project. Through this project, I learned and utilized various AWS services, including Amazon S3, AWS Lambda, Amazon API Gateway, Amazon DynamoDB, AWS Elemental MediaConvert, Amazon CloudFront, Amazon Cognito, AWS Identity and Access Management (IAM), and Amazon CloudWatch. In addition, I gained hands-on experience in developing RESTful APIs, managing application data, implementing video upload and transcoding workflows, deploying cloud-based applications, and testing system functionalities.

Besides enhancing my technical knowledge, I also learned how to collaborate effectively within a development team by using Git and GitHub for source code management, communicating with team members, and incorporating feedback from my supervisor to improve the project. This internship provided me with a better understanding of the software development lifecycle, system analysis and design, and problem-solving techniques applied in real-world software projects.

Regarding my work attitude, I consistently made every effort to complete assigned tasks on time, complied with the company’s regulations, proactively explored new technologies, and actively sought guidance whenever I encountered difficulties. Although I still have many areas that require further improvement, this internship significantly enhanced both my technical competencies and my professional working skills.

Areas for Improvement

After completing the internship, I realized that there are still several aspects that I need to improve in order to better meet the requirements of future professional work:

  • Continue expanding my knowledge of AWS services and Serverless architecture to design and implement large-scale cloud applications more effectively.
  • Improve my understanding of system performance optimization, security best practices, and application monitoring in cloud environments.
  • Strengthen my skills in requirement analysis and system design before implementation to reduce unnecessary revisions during development.
  • Enhance my communication and technical presentation skills to collaborate more effectively with colleagues and project stakeholders.
  • Continue improving my technical English reading skills to better understand technical documentation and keep up with emerging technologies.
  • Learn more about DevOps practices, CI/CD pipelines, Infrastructure as Code (IaC), and modern cloud deployment methodologies to better prepare for my future career.

Conclusion

My internship at Amazon Web Services Vietnam Company Limited was a valuable opportunity that allowed me to experience a professional working environment, reinforce the knowledge acquired during my university studies, and gain practical experience in cloud computing. Throughout the internship, I was able to apply my knowledge of software development, AWS services, and Serverless architecture to a real-world project while improving my teamwork, communication, and problem-solving skills.

The knowledge and practical experience gained during this internship have provided me with a solid foundation for continuing my studies, conducting further research, and pursuing a professional career in the field of Information Technology after graduation.
